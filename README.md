
## 📝 Student Registration System

A full-stack **Student Registration Web Application** built with a modern dark-themed UI. The system allows administrators or staff to register students and view all registered entries in a tabular format.

### 🚀 Features

- **Student Registration Form** — Collects Full Name, Email Address, Date of Birth, Department, and Phone Number
- **Department Selection** — Dropdown to assign students to their respective departments
- **Success Feedback** — Displays a confirmation message upon successful registration
- **Registered Students Table** — Lists all registered students with columns for Name, Email, Date of Birth, Department, Phone, and Registration Date
- **Refresh Button** — Fetches the latest registered students from the backend on demand

### 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React.js / HTML + CSS |
| Backend | Spring Boot (Java) |
| Database | MySQL / PostgreSQL |
| Styling | Custom CSS (Dark Theme) |

### 🎨 UI

Dark navy-themed interface with pink accent colors, rounded card layout, and a responsive two-column form grid.

### 📦 Getting Started

# Start the backend (Spring Boot)
cd backend
./mvnw spring-boot:run

# Start the frontend
cd frontend
npm install && npm start
```

The app runs at `http://localhost:3000`
